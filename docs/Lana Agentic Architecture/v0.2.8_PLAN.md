## §3 · v0.2.8 HTML task · nav-collapse-when-Lana-present

### The behavior
When any of these are visible on a screen:
- `.lana-status` (top pill with the "Lana · ___" state) AND
- `.bubble-3d` OR `.lana-inline-hint` (a Lana speech bubble) is rendered with content

→ the screen MUST show only **ONE primary CTA**. The 3-button rail (`PROFILE · RADAR · CHATS`) is **hidden** until the Lana moment is dismissed/quiet.

### The why
- Lana is speaking · the user's attention belongs to Lana's question + one response action
- 3-button rail at the same time fights for attention
- "Less is more" for the first-impression and high-stakes moments

### The CSS contract (proposed)
Add a CSS rule that hides `.lana-rail` when its sibling has an active Lana-bubble context. Simplest approach:

```css
/* v0.2.8 · nav collapses when Lana is actively speaking */
.phone-screen.lana-speaking .lana-rail {
  display: none;
}
.phone-screen.lana-speaking .voice-stage {
  /* center the bell as the single primary action */
  justify-content: center;
}
```

Then add `class="lana-speaking"` to the `<div class="phone-screen">` wrapper of any frame where Lana is mid-bubble. This is a **per-frame opt-in** so the team can selectively apply.

### Which frames get `.lana-speaking`?
- All FTUE frames (C-INTRO-1, C-INTRO-2)
- All capture frames (C-3-look, C-4-look-swap-P1, C-4-look-swap-P2, profile-prompt, profile-extract)
- All signup frames (C-SIGNUP-1 through 4)
- All sign-in frames (C-SIGNIN-1 through 3)
- The non-ICP off-ramp

**NOT applied** to:
- Frames showing populated RADAR popover (mom is browsing her own data · rail stays)
- Frames where Lana is "listening for you" with no active prompt (rail can stay)
- Frames showing the joint-moment ack (post-nudge confirmation · rail belongs there)

### Implementation (subagent task)
1. Add the CSS rule once (top of `<style>` block)
2. Add `class="phone-screen lana-speaking"` to identified frames (estimated ~25-30 frames)
3. Verify the bell is centered when nav is hidden (or the single primary CTA · whichever is the active step)
4. Same treatment in the explorer's frame-inline previews
5. Bump to v0.2.8

This becomes a single explicit subagent dispatch in the next batch.
